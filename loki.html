👩👨Modular Character System

We needed a lot of characters to fill the town, so I created this little system to create lots of them quickly. ​


🧠 Enemy AI

I've coded a system where when the player changes appearance, the guards don't recognise us. Each enemy has a memory, but they can communicate with each other about suspicious appearances.


🐈 Cat gameplay 

One of our characters is a cat, and to prevent the player from jumping around and getting stuck, I developed this (lightweight and optimised) jumping system that checks before each jump whether the cat is going to get stuck. .


🎥 Unreal Sequencer  

I used the Unreal sequencer a lot to create the cinematics.
